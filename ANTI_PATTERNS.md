- **Суммы exp(miqdor) как «объём денег»** слабее средних (AUC 0.487 vs 0.461): эффект числа транзакций (+) и уровня сумм (−) гасят друг друга в сумме. Не заменять средние/квантили суммами; если добавлять объёмы — только вместе с count и средним. (E004)

- **Связывать сигналы в клиентов (IEEE UID)**: общих транзакций между сигналами нет. (E002)
- **Фичи времени суток / дня недели**: таймстемпы внутри дня равномерны, у классов распределения совпадают. (E007)
- **Отношения «недавняя активность / старая»**: AUC ≈ 0.500. (E006)
- **«Денойзинг» miqdor (AmEx/raddar)**: скрытых дискретных сумм под шумом нет. Ложные «пики» в тесте гребёнки давал сглаживатель с `mode='nearest'` на краю обрезанного диапазона → такие тесты смотреть только по внутренним бинам. (E008)

- Поминутные бины на 60 минут скрыли форму burst (он длится ~2.8 мин) → для burst брать 10-секундные бины на последних 10 минутах.
- `PercentFormatter(decimals=0)` на оси с диапазоном < 10% даёт дублирующиеся подписи (0%, 0%, 1%…) → число знаков выбирать по диапазону.
